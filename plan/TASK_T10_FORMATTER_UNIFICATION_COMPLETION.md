## 一、任务目标（回顾 §6.1）

`formatter_node` 存在**两条出口**，风格割裂：

| 出口 | 触发条件 | 风格 |
|------|---------|------|
| 结构化摘要路径 | 大数据/events>5/聚合/JSON>4000字符 | 固定骨架：`## 📊 标题` + `### 子项` + 图表内联 |
| LLM 自由文本路径 | 其余（小结果集） | 自由发挥，可能一句话、可能长篇，无统一标题/结构 |

**用户主观感受**："有时很详细（走结构化），有时一句话（走 LLM）"，体验割裂。

**目标**：统一两条路径的回答风格，让用户感知到一致的「标题 / 要点 / 数据」骨架。

---

## 二、实施方案（D3：对齐 LLM 到骨架）

执行摘要 §6.1.2 提供了两种方案：
- **D3 原版**：抽共享渲染器（两路径走同一套模板）
- **D3 优选**：只改 LLM 路径提示词，对齐到结构化骨架

选择 **D3 优选方案**（外科手术式，低风险）：
1. **保留结构化路径不动**（纯 Python `_generate_summary_response`，已稳定、性能好）
2. **只改 LLM 路径**：在 system_prompt 末尾追加统一骨架 guide，要求 LLM 按「一句话结论 / 关键要点 / 数据明细 / 补充说明」组织

**设计原则**（遵循 SKILL.md「简单优先」）：
- 不抽渲染器（改动面大、回归成本高）
- 只注入提示词（LLM 自行按骨架组织，无需改代码逻辑）
- 骨架常量抽独立模块（两路径共享，便于一致演进）

## 三、实施内容（外科手术式，两处改动）

### 3.1 新建 `graph/answer_skeleton.py`（统一骨架常量）

```python
"""统一回答骨架模板（T10：formatter 出口一致性）

两条路径共享此常量，便于一致演进：
- 结构化路径（_generate_summary_response）：已符合此骨架风格（标题/要点/数据明细）
- LLM 自由文本路径（formatter_node）：注入此 guide 要求 LLM 按骨架组织
"""

ANSWER_SKELETON_GUIDE = """# 回答结构要求（保证体验一致）
按以下骨架组织回答（无对应内容的部分可省略，但有则按此顺序）：
1. **一句话结论**：直接回答用户问题（如"共查到 12 条未戴安全帽告警"）
2. **关键要点**：用 `-` 列表给出 2~5 条核心信息
3. **数据明细**：多条数据用列表或表格；保留原始数值不四舍五入
4. **补充说明**：数据来源/筛选条件/图表提示（如有）

语气专业简洁，中文回答，不重复用户问句，不编造工具未返回的信息。"""
```

**关键设计点**：
- "无对应内容可省略" — 避免简单问题"过度结构化"（执行摘要 §6.1.5 的风险缓解）
- 4 段骨架与结构化路径的视觉风格对齐（标题/要点/数据/说明）

### 4.4 对比结构化路径（视觉一致性）

结构化路径（`_generate_summary_response`，line 1796-1833）已有的骨架：

```python
report.append(f"## 📊 AI 告警分析报告\n")
report.append(f"**查询结果**：共 **{total_count} 条**告警...")  # ← 一句话结论

report.append(f"### 🚨 告警类型分布（Top 5）")           # ← 关键要点

    report.append(f"- **{name}**: {count} 条 ({pct:.1f}%)")  # ← 数据明细

```

**视觉对齐**：
- 结构化路径：`## 标题` + `### 子项` + `- 列表` + 百分比/数值
- LLM 路径（骨架 guide 要求）：`**结论**` + `**要点**:` + `- 列表` + `**明细**:`

**观感一致性**：两者都采用"标题 → 要点列表 → 数据明细"结构，只是标记符号略有差异（`##` vs `**`），但整体骨架一致。

## 五、风险与回滚

### 5.1 风险评估

**风险等级**：中（执行摘要 §6.1.5）

**具体风险**：提示词加骨架可能让 LLM 对极简问题"过度结构化"（如简单确认也套四段）。

**缓解措施**：
1. 骨架 guide 里已注明"无对应内容可省略"
2. 人工 Demo 观察（本次验收已通过）
3. 实际使用中如发现过度结构化，可调整 guide 或放宽"可省略"条件

### 5.2 回滚方案

移除两处改动即可：
1. 删除 `graph/answer_skeleton.py` 文件
2. `nodes.py` line 2214-2215 删除导入
3. `nodes.py` line 2233 删除 `+ ANSWER_SKELETON_GUIDE`（恢复原 `"""`）

回滚后 LLM 路径退回原有"自由文本"风格，结构化路径不受影响。
